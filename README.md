# LP — Playbook Treinamento Corporativo 4.0 · Instituto Axon

Landing page de vendas do Playbook Treinamento Corporativo 4.0, do Instituto Axon (Joe Weider).

## Estrutura

- `index.html` — página completa (HTML + CSS + JS em um único arquivo)
- `assets/` — imagens e logos usados pela página
- `_fontes/` — arquivos-fonte e versões anteriores (fora do repositório)

## Stack

HTML e CSS puros, sem dependências. Fontes via Google Fonts (Bricolage Grotesque + Instrument Sans).

## Publicação

Servida via GitHub Pages a partir da branch `main`.

## Pendências

- Substituir o `href="#"` do botão de compra na seção de oferta pelo link do checkout.
- Substituir o `href="#"` de "Termos de Compra" no rodapé.
